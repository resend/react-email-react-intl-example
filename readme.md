# React Email with react-intl 

This example shows how to use Resend with [react-intl](https://formatjs.github.io/docs/react-intl).

## Instructions

1. Install dependencies

  ```sh
npm install
  ```

2. Run Preview Server locally:

  ```sh
npm run dev
  ```

3. Open URL in the browser:

  ```
http://localhost:3000
  ```
